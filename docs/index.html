Git Commit Graph

Render the full history as an interactive multi-lane graph: SVG curves, glowing HEAD ring, branch / tag / environment badges.

  • Per-branch lane colors with Bézier-curve merge edges
  • Inline branch & tag pills, environment hex badges (⬡)
  • ⚠ marker on infra / terraform / helm / k8s commits
  • Filters: keyword, regex, author, branch, date range, path
  • Filter Presets — save and reload any combination (Pro)
  • History limit: 500 commits (Free) · 5,000 (Pro)

Smart Diff — three context modes

Stop reading walls of text. Smart Diff understands the structure of your files and reports what actually changed, grouped by the work you are doing.

  • Development Diff — working tree, staged, last commit, vs origin/main, custom refs
  • Release Diff — any tag/branch pair, structured files trigger semantic analysis automatically
  • Workflow Diff — auto-filtered to CI/CD & infra files, grouped by GitHub Actions / Docker / Terraform / K8s / Helm
  • Side-by-side viewer with synchronized scroll and intra-line character highlighting (Pro)

Commit Detail & Diff Viewer

Click any commit to see full metadata, change list and diff in a side panel — never leave the graph.

  • Collapsible file tree with A / M / D / R badges and +/− line counts
  • Unified diff with token-level coloring
  • Side-by-side diff with synced scroll & character-level highlights (Pro)

Release Workspace

A six-tab dashboard built from your Git history alone — no external integrations needed.

  • Launchpad — one-click pre-flight check with status banner, risk score, sync table and a Markdown export (Pro)
  • Changelog — compare any two refs, classify by Conventional Commits, copy as Markdown (generation Pro)
  • Actions — hotfix sync detector across main/develop/master, lightweight-tag warnings (Pro)
  • Environments — pipeline grid with adjacent-pair ahead/behind, env hex badges in the graph (Pro)
  • Velocity — release frequency, hotfix rate, avg commits per release, scrollable history table (Pro)
  • Hotfix Wizard — 4-step guided flow: pick prod ref → name branch → cherry-pick → execute & sync-check (Pro)

File Timeline

Type a file path. See every commit that touched it. Click any two commits — get the side-by-side diff for that exact pair.

  • Per-file commit history with branch/tag annotations and "most recent" marker
  • Optional release-range filter — scope the timeline to between two refs
  • Auto-orders the two picks by commit timestamp — click in any order
  • Jump to Timeline straight from any Smart Diff file (Pro)

Multi-Repo Release View

Run one runtime per repository, then aggregate ahead / behind across all of them in a single table. Built for microservices and split-repo releases.

  • Add any number of endpoints — each pointing to a runtime + repo
  • Compare a base/head ref pair across every endpoint at once
  • Per-row status: ✓ ok · connected · ✗ error (one failure does not break the rest)
  • Endpoints persist in browser localStorage — re-open and the table is intact

Worktrees & Workspace Profiles

Manage parallel checkouts and switch repository contexts in seconds — no terminal hopping, no stash juggling.

  • Worktrees — list, add and remove linked worktrees (Pro). MAIN / LOCKED status badges
  • Workspace Profiles — name a folder once, reload as the active repo with a click
  • Branch-name validation enforces Git rules before any action runs
  • Active profile shown with a green indicator dot

Remotes & Credentials

A first-class credential manager for hosted Git platforms — fetch and push without ever leaving the editor.

  • Auto-detected platform per remote — GitHub · GitLab · Self-hosted · Azure DevOps · Gitea
  • PATs encrypted at rest with an HMAC-signed entry, masked in the UI
  • One-click Fetch per remote · push uses the matching credential automatically
  • Credential is never sent anywhere except the matching Git host
