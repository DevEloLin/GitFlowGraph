Git 提交图谱

以交互式多泳道图可视化完整历史，SVG 边缘曲线、发光 HEAD 指示器、环境徽章一应俱全。

  • 每分支独立颜色，贝塞尔曲线连接合并边
  • 提交内联显示分支 & Tag 胶囊标签
  • ⬡ 环境部署徽章标记已上线提交
  • ⚠️ 自动识别 infra / terraform / helm 类提交
  • 关键字、正则、作者、分支、日期范围、文件路径多维过滤
  • 右键菜单：Checkout、新建分支、Cherry-pick、Reset 等

Smart Diff — 三种上下文模式

不再阅读纯文本差异墙。Smart Diff 理解文件的结构，精确汇报逻辑变更，并按工作上下文分为三种模式。

  • 开发 Diff — 工作区、暂存区、最近提交、分支 vs 基准对比
  • 发布 Diff — 任意 Tag / 分支对比，结构化文件自动语义分析
  • 工作流 Diff — 自动筛选 CI/CD 文件，按 GitHub Actions / Docker / Terraform / K8s / Helm 分组

提交详情 & Diff 查看器

点击任意提交，无需跳转，直接在侧边面板查看完整变更详情。

  • 可折叠目录树，含 A / M / D / R 状态徽章及增减行数
  • 统一 Diff — 经典 +/- 行差异，token 级着色
  • 左右并排 Diff — 字符级行内高亮，双栏同步滚动
  • 文件历史 — 查看选中文件被修改的所有提交
  • 二进制文件检测，优雅提示而非乱码

发布管理

从 Git 历史直接提取发布情报，无需任何外部集成。

  • 变更日志 — 对比任意两 ref，自动生成 Breaking / Feature / Fix / Infra 分类日志，支持 Markdown 导出
  • 发布风险评分 — 0–100 评分，文件级风险因素明细
  • Actions — Hotfix 分支同步状态检查，无发布说明 Tag 检测
  • Environments — 环境流水线网格，实时显示各环境领先 / 落后提交数
  • 速度仪表板 — 发布频率、Hotfix 占比、平均提交数等指标
  • Hotfix 向导 — 4 步引导式紧急修复工作流，含脚本预览和一键执行

Worktrees & 工作区档案

在编辑器内管理 Git 工作树，快速切换多仓库上下文。

  • 列出所有工作树：路径、分支、HEAD、MAIN / LOCKED 状态
  • 添加 / 删除工作树，无需离开编辑器
  • 命名工作区配置档案，一键切换活跃仓库
