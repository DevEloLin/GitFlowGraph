Frequently asked questions

What's included in the free plan?

The free plan gives you the full Git commit graph, commit table view, unified and side-by-side diff viewer, branch and tag labels, all search and filter options, and context-menu Git actions (checkout, branch, tag, cherry-pick, soft/hard reset) — for a single repository, forever.

How does the 30-day trial work?

When you install GitFlowGraph, every Pro feature is automatically unlocked for 30 days at no cost. No credit card is required to start. At the end of the trial, Pro features are gated until a license is activated — the free tier continues working without any interruption.

Does my data ever leave my machine?

No. All Git operations — reading history, generating diffs, parsing files — run entirely locally using the bundled runtime binary. No commit data, diff content, or file contents are ever sent to any server. License validation communicates only a license key hash, not any repository data.

What is Smart Diff exactly?

Smart Diff is a semantic diffing engine that understands the structure of YAML, JSON, and Terraform/HCL files. Instead of showing raw line changes, it reports what logically changed — for example spec.template.containers[0].image: nginx:1.24 → nginx:1.25 — with the full structural path so you always know precisely what changed and where.

Can I use GitFlowGraph with private repositories?

Yes. GitFlowGraph works with any local Git repository — private or public, hosted anywhere or fully offline. It reads your repo directly from disk via the bundled runtime and never needs network access to the remote for graph rendering or diff viewing.

What happens if I cancel my Pro subscription?

If you cancel, your account moves to the free tier at the end of the current billing period. The core Git graph and diff viewer remain fully functional. Smart Diff, Release Flow, and Cross-Repo Timeline become unavailable until a new license is activated.
