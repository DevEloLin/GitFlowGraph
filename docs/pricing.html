Frequently asked questions

What's included in the Free tier?

The full Git commit graph (up to 500 commits per request), unified diff with token coloring, file tree, branch/tag/environment badges, keyword · regex · author · branch search, the read-only Release compare, Workspace Profiles, and the Remotes credential manager. Right-click is limited to the four Copy actions and View Diff. Forever free, no account.

How does the 30-day trial work?

On the License panel click Start Free Trial. Every Pro feature unlocks for 30 days, no credit card. When the trial ends, the editor reverts to Free — your data, environments, profiles and credentials all stay intact. Activate a Pro key any time to restore full access.

Does my data ever leave my machine?

No. The runtime is a local Rust binary on localhost:9876. Reading history, generating diffs, parsing YAML/JSON/Terraform — all of it runs on your machine. The only outbound network call is license activation against Lemon Squeezy (no repository data is ever sent).

What is Smart Diff exactly?

A semantic diff engine that understands the structure of YAML, JSON and Terraform/HCL files. Instead of "lines 14–15 changed" you get spec.template.containers[0].image: nginx:1.24 → nginx:1.25 — the dot-path, old value and new value, with auto-categorisation for added / removed / modified / moved.

Can I use GitFlowGraph with private repositories?

Yes. The runtime reads any local Git repo from disk — public or private, online or fully offline. For network operations (push / fetch) configure a PAT in the Remotes panel; the credential is HMAC-signed and only ever sent to the matching host.

What happens if I cancel Pro?

You drop back to Free at the end of the billing period. The Git Graph, unified diff and Release compare keep working forever. Smart Diff, Release Workspace, File Timeline, Multi-Repo and Worktrees lock until a license is re-activated. No data is deleted.
