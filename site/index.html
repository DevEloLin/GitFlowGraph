Git Commit Graph

Visualize your entire history as an interactive graph with color-coded branch lanes, merge-edge Bézier curves, and a glowing HEAD indicator.

  • Color-coded lane per branch with SVG edge curves
  • Inline branch & tag pill badges on every commit
  • Filter by keyword, regex, author, date range, or file path
  • Right-click menu: checkout, branch, tag, cherry-pick, reset
Git Graph screenshot

Smart Diff

Stop reading wall-of-text diffs. Smart Diff understands the shape of your config files and reports what logically changed — with full structural paths.

Release Flow

Pick any two refs and instantly see what's in-flight between your environments — with a one-click Markdown changelog.

  • Compare any branch, tag, or commit SHA
  • Chronological commit list between the two refs
  • Auto-generated changelog grouped by conventional commit type
  • Hotfix detection for cherry-picked commits
Release Flow screenshot

Cross-Repo Timeline

One scrollable timeline of commits across all your repositories. Stop switching terminals to understand what shipped when.

  • Up to 5 repositories in one unified workspace
  • All commits merged into a single chronological view
  • Author and keyword search across all repos simultaneously
  • ⌘1 ⌘2 ⌘3 to switch the active repo
